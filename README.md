# Cupcake Social

Cupcake Social es una aplicación móvil desarrollada en Android Studio con Kotlin, Jetpack Compose y Material 3. La app simula un perfil social interactivo, donde el usuario puede editar su información personal, seleccionar una foto de perfil, crear publicaciones con texto e imagen, reaccionar con “Me gusta”, compartir publicaciones y agregar comentarios.

El proyecto está enfocado en practicar el uso de componentes modernos de Jetpack Compose, manejo de estados con `remember`, selección de imágenes desde el dispositivo, validaciones de formularios y organización visual mediante Cards, Rows, Columns, Boxes y Spacers.

## Funcionalidades principales

- Edición de perfil con nombre, usuario y descripción.
- Selección de foto de perfil desde la galería.
- Creación de publicaciones con texto e imagen.
- Validación de campos vacíos y límites de caracteres.
- Sistema de “Me gusta” y “Compartir” dinámico.
- Comentarios en publicaciones con usuario y hora.
- Interfaz inspirada en perfiles reales de redes sociales.
- Diseño con Jetpack Compose y Material 3.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
